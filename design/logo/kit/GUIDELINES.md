# SolaCliq — Logo Guidelines (compact)

SolaCliq is MarkCliq's product for solar EPC vendors. Its mark says so:
**SolaCliq's sun rising behind MarkCliq's awning**, MarkCliq's own sign
(owner's choice, 2026-11-17). Not yet trademark-checked: run a
professional search before printing it widely.

## 1. The logo

| Version | File (`svg/`) | Use it for |
|---|---|---|
| App icon | `solacliq-icon.svg` (`-dark`) | The app, store listings, profile pictures |
| Symbol | `solacliq-symbol.svg` (`-dark`, `-black`, `-white`) | Next to other content, merchandise, stamps |
| Horizontal lockup | `solacliq-lockup-horizontal.svg` (`-dark`) | Website header, letterheads, slides, emails |
| Stacked lockup | `solacliq-lockup-stacked.svg` (`-dark`) | Square spaces: posters, the app's welcome screen |
| Wordmark | `solacliq-wordmark.svg` (`-dark`, `-black`) | Where the symbol is already shown nearby |
| Small cut | `solacliq-symbol-small.svg`, `solacliq-icon-small.svg` | 24 px and below: favicon, status bar |

The wordmark is set the way MarkCliq's is: **Sola** upright, ***Cliq***
italic and grey, with the i's dot as the sun (MarkCliq's dot is red).

## 2. Clear space

Keep empty space around the logo at least the height of the awning's
**rail plus one scallop** (about a fifth of the symbol's height) on
every side. Nothing (text, edges, other logos) inside it.

## 3. Minimum size

- Symbol: 32 px / 8 mm tall. Below that, use the small cut.
- Small cut: down to 16 px (favicon, status bar).
- Horizontal lockup: 120 px / 30 mm wide.

## 4. Colour

Two brand colours, three neutrals.

| Name | HEX | RGB | Role |
|---|---|---|---|
| MarkCliq rust | `#B2402C` | 178 64 44 | The awning (MarkCliq's own red) |
| Sun | `#F6C445` | 246 196 69 | The sun, the i's dot |
| Ink | `#2A1F19` | 42 31 25 | The rail, "Sola" |
| Cream | `#FBF8F4` | 251 248 244 | The app icon's tile |
| White | `#FFFFFF` | 255 255 255 | The awning's light stripes |

On dark backgrounds use the `-dark` files: the rust is lifted to
`#D2553F`, ink parts turn cream. One colour (embroidery, stamps,
engraving): `-black` or `-white`, where the light stripes become holes.
Print colours (CMYK, Pantone) are not matched yet: ask the printer for a
proof against the HEX values.

## 5. Typography

The wordmark's letters are outlines of **Inter** (SemiBold), the app's
own font, SIL Open Font License (logo use allowed). "Cliq" is slanted
10°, MarkCliq's italic. Never retype the wordmark: use the files.

## 6. Don'ts

- Don't recolour the awning (it is MarkCliq's red) or the sun.
- Don't move the sun to the centre of a bare rail without the stripes:
  it then reads as a hat.
- Don't stretch, rotate, outline or add shadows or gradients.
- Don't put the full-colour logo on busy photos; use a solid panel.
- Don't use the full symbol below 32 px: the stripes blur. Use the small cut.

## 7. Files and changes

Everything is generated by `build_kit.py` from one geometry. To change the
logo, edit the geometry there and run (from the repo root, with fontTools):

```
python3 design/logo/kit/build_kit.py
```

It rewrites the SVGs, PNGs (`png/`), web icons (`web/`, including
`favicon.ico`) and the app's Android icons for all three flavours
(launcher, round, themed monochrome, the status-bar icon; dev and
staging keep their DEV/STG badge from `android-badges/`).
